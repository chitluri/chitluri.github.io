Private LLM

Private LLM is a personal, non-commercial tool operated by Gopi Krishna Chitluri. It lets the owner's own self-hosted language models read and manage the owner's own Gmail account through the Gmail API.

It is not a public service and is not offered to anyone else.

Privacy Policy

Last updated: October 14, 2026

  • Who uses it: Only the owner, signing in with their own Google account.
  • Data accessed: Gmail messages and related metadata from the owner's account, only within the permissions the owner grants on Google's consent screen.
  • How data is used: Solely to provide the owner's private LLM tools with access to the owner's own email. Data is processed on the owner's own systems.
  • Sharing: No data is sold, shared with third parties, or used for advertising.
  • Storage and deletion: OAuth tokens are stored only on the owner's systems. Access can be revoked at any time at myaccount.google.com/permissions.
  • Google API Services: Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
